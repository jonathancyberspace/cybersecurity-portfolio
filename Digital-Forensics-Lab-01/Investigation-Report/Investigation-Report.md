\## 3. Evidence Examined

The following files were added to Autopsy:



\- evidence.txt

\- notes.txt

\- sample.txt



\## 4. Examination Process

1\. Created a forensic practice folder.

2\. Added the sample files as a logical file data source in Autopsy.

3\. Configured the ingestion modules.

4\. Examined the extracted text.

5\. Reviewed the available file metadata and file type information.



\## 5. Findings and Observations

Autopsy successfully ingested the three sample text files.



The extracted text from sample.txt contained:



"This is my first digital forensics practice file."



The displayed metadata timestamps were zeroed or unavailable. Therefore, reliable file creation and modification times could not be established from the displayed results.



\## 6. Conclusion

This exercise provided practical experience with Autopsy and the digital forensic examination workflow.
